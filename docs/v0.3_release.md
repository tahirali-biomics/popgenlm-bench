# PopGenLM Bench v0.3 release

PopGenLM Bench v0.3 adds an evolutionary-evidence results layer while keeping the v0.1, v0.2, and v0.3 benchmarks active, versioned, documented, and runnable side by side.

## Scope and released assets

The release contains a deterministic 10,000-variant *Arabidopsis thaliana* master table with population counts, GPN and PlantCAD scores, signed site-oriented PhyloP, and exclusive genomic-context annotations. It also releases model-concordance tables, context-stratified correlations, fixed physical-bin assignments, LD-thinning membership, deterministic bootstrap intervals, and sample-quality/UMAP tables. The two figures are [model evidence](../figures/v0.3/model_evidence.svg) and [genotype UMAP geography](../figures/v0.3/genotype_umap_geography.svg), each with a PNG companion.

The primary population-oriented score is `log P(minor allele) - log P(major allele)`. Raw model columns retain the separate `log P(ALT) - log P(REF)` orientation. Positive values favor the first term in the stated difference; negative values favor the second. PhyloP is a signed site-oriented conservation score, not an allele-oriented score.

## Validation and provenance

Production generation and scientific contracts are documented in [v0.3 production provenance](v0.3_production_provenance.md). The release manifest records the portable path, SHA-256, byte size, scientific role, and TSV dimensions for exactly the 14 promoted assets. [SHA256SUMS.txt](../data/benchmarks/v0.3/SHA256SUMS.txt) provides the same deterministic file set for command-line verification.

The reported correlations and bootstrap intervals are descriptive summaries of precomputed production results. This release claims no hypothesis-test p-values. LD thinning uses fixed physical bins and deterministic profiles; genotype UMAP uses the validated production settings. The publication notebook only validates, loads, summarizes, and displays these frozen assets; it does not run inference, VCF processing, UMAP fitting, bootstrap resampling, or production analysis.

## Key descriptive results

Across the 10,000 variants, GPN and PlantCAD population-oriented scores have Spearman correlation 0.6525 (Pearson 0.6331). The GPN–PhyloP Spearman correlation is -0.1876 across 9,453 variants with covered PhyloP. Across the released LD profiles, the GPN–PlantCAD population-oriented Spearman estimate remains approximately 0.6523–0.6534. Context-stratified GPN–PlantCAD Spearman estimates range from 0.5171 in coding CDS to 0.7349 in intergenic variants. These are associations among scores and annotations, not evidence that a model directly measures fitness, selection, or pathogenicity.

The genotype-quality table covers 1,135 samples; 1,093 enter the primary call-rate set and 996 enter the strict set. Geographic metadata is available for 1,131 samples. These summaries describe sample quality and structure; they are not a population-genetic inference beyond the released production analysis.

## Use locally or in Colab

Open [the v0.3 results notebook](../notebooks/popgenlm-bench-v0.3.ipynb). Locally it prefers files in this repository. In Colab, it uses the pinned `v0.3.0` raw GitHub path when a local repository copy is unavailable. In either case, every downloaded or local asset is checked against `manifest.json` before it is read. The notebook needs only standard Python data-frame and notebook display dependencies; it does not require a GPU or the optional PlantCAD/PyTorch stack.

## Limitations and reproducibility

This is a benchmark and evidence-integration release, not a causal evolutionary test. Population structure, demography, linkage disequilibrium, ascertainment, allele age, annotation coverage, score calibration, and model-specific training data can affect these descriptive relationships. No p-values are reported. Reproduce the file-level release check with `sha256sum -c data/benchmarks/v0.3/SHA256SUMS.txt` from the repository root, and retain the manifest alongside any copied assets.
