# v0.4 regulatory prioritization pilot (review draft)

This implementation starts from v0.3.0 (`4c4258f4a8014d4ee2b19e32329362baf34c44a0`). Production artifacts live outside Git at `/projects/ag-demeaux/tali/PopGenLM/runs/v0.4/regulatory_pilot_20261114`.

The benchmark is frozen before model inference on pilot candidates. Technical smoke SNPs are separate synthetic fixtures. The study asks whether adding model scores changes top-five recovery relative to association, LD and standard annotations. Discovery and held-out accessions are assigned by a deterministic accession hash before mapping. A null-REML linear mixed model uses chromosome-excluded relatedness from the verified v0.3 genotype matrix. This is a new processed-GEO mapping pilot, not a reproduction of the published Voichek GEMMA batch analysis.

The Voichek published phenotype inventory seeds discovery. Isolated reporter substitutions from supplementary tables S3/S4 are mapped through their exact oligos to TAIR10.1 and the full VCF. Natural allele matches qualify as exploratory nucleotide reporter support only when both minimal-promoter activity differences have consistent signs and absolute differences of at least 0.5. No per-variant assay uncertainty is available. Haplotype support, lead association, motif overlap and fine-mapping PIP do not establish a causal nucleotide. Assay audit and screen exclusions are retained, including supported variants that fail the pilot's common-SNP, association or LD criteria.

Loci span gene boundaries plus 10 kb on both sides. Candidate common biallelic SNPs have discovery call rate >=0.9, MAF >=0.05, and pairwise-complete dosage r² >=0.6 with the discovery lead. Each locus needs at least six linked candidates. Neighboring windows are excluded; entire chromosomes form evaluation blocks. Eight eligible loci per chromosome give a target of 40. No ranking weights are fitted. Fixed coefficients and the five-locus AlphaGenome subset are recorded in the frozen protocol.

PlantCAD2-S uses pinned revision `f756c255cb76e9f538c3acec04acf4214ed03fb3` at 512 and 4096 bases. Original PlantCAD uses the existing validated l32 checkpoint at 512 bases. Original GPN uses `songlab/gpn-brassicales` revision `eb9c35d0d18571abe84390d22e74f2b21d319ce3` at 512 bases and its official centered mask convention. All allele LLRs are masked ALT-minus-REF, averaged over forward and reverse complement, and retained separately from minor-minus-major orientation. Absolute LLR is used for prioritization. Each chromosome/context is restartable with a hash-checked completion record.

The maintained nemo bundle at `KRockenbach/nemo` revision `c8deaaf18a8bd174300bf40e11fa2c69c0d6bb4e` contains B. napus weights. It is evaluated explicitly as transfer on Arabidopsis, not relabeled an Arabidopsis-trained model. Its 6200-base promoter/terminator windows use transcript orientation, global CDS masking and the longest annotated mRNA. Masked CDS and out-of-window variants are uncovered. Paired effects are unrounded ALT-minus-REF log10(TPM+0.1); magnitudes and directions are distinct. The publication's Arabidopsis models used E-CURD-1; exact family/training partition metadata for the released B. napus bundle are unavailable, so family-independent validation is not claimed.

Botanic1-S is gated and the existing local authorization check returned HTTP 401. AlphaGenome access has no configured API key. Neither is represented by fabricated scores or another checkpoint. The frozen AlphaGenome subset and exploratory central RNA-seq-track aggregation remain available for a future authorized run.

Primary results use the paired change in recovery of supported nucleotides, with explicit denominators and chromosome-block bootstrap uncertainty. Small nucleotide denominators are case studies. Secondary results recover a held-out mapping lead on the discovery-frozen candidates, conditional on a held-out locus association; this is same-study sample holdout, not external replication or causal identification. For every model the baseline uses identical covered candidates, and a shared intersection is reported. Discovery lead agreement is descriptive only.

Run `scripts/v0.4/analyze_pilot.py --run /absolute/path/to/pilot` on CPU using frozen inputs and scores. The packaged notebook checks hashes and pins the release base plus reviewed implementation revision; publication and a v0.4 tag remain deferred.
