It includes PopGenLM source code, attributed scholarly figures, and a compact 300-pair plotting table for the dedicated nemo Figure 2D adaptation.

## Source-specific terms

- **Botanic1-S:** the applied checkpoint and license revision are `living-models/Botanic1-S` at `813d2d46ca40ab5cd91a6acaa8852d636224992e`; the retained license copy has SHA-256 `9276bb71478fc018d9da80ea7345cb882816c37fe027d7d84f1f5a199c60048f`. The license’s Sections **2(c)** and **4** allow research publication of outputs; Sections **3(a–c)** require attribution/notices and research-only use. Section **3(d)** contains non-transferability language, so raw score columns and weights are not redistributed as reusable files. Figures are scholarly aggregate outputs with the provider notice, not raw tables or a transfer of the checkpoint. Cite Barozet et al. (2026), bioRxiv v3, [doi:10.64898/2026.09.04.749355](https://doi.org/10.64898/2026.09.04.749355).
- **AlphaGenome:** API/model identity is `alphagenome.models.v1`, AlphaGenome 1, SDK 0.11.0; the remote server weight digest is unavailable. Direct API outputs are governed by the [AlphaGenome Output Terms](https://deepmind.google.com/science/alphagenome/output-terms) and [Services Additional Terms](https://deepmind.google.com/science/alphagenome/terms); the v0.4 data-terms audit records the inspected effective versions. The terms permit publication/sharing/adaptation with notice and impose research-use restrictions. This page’s v0.5 expression plots do not call AlphaGenome tracks plant expression. Full API arrays are not bundled because they are not needed for this development update; a fresh API analysis requires an authorized user/API setup. Cite Avsec et al. (2026), [doi:10.1038/s41586-025-10014-0](https://doi.org/10.1038/s41586-025-10014-0).
- **GEO GSE80744:** the source is publicly available and the NCBI policy states NCBI itself imposes no restrictions on molecular data use/distribution; it also notes submitters may assert rights and that NCBI transfers no rights. The record lists no dataset-specific license. The small, attributed figure-data excerpt is included for scholarly reproducibility; do not infer a new blanket license from the NCBI archive or from this project’s Apache-2.0 code license. For a full reanalysis, obtain the source expression matrix and metadata from the [GSE80744 record](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE80744), then use the published/PopGenLM preparation instructions and frozen gene IDs. See [NCBI Molecular Data Usage](https://www.ncbi.nlm.nih.gov/home/about/policies/).
- **All model weights/checkpoints:** none are included. They are unnecessary for these cached-output reanalyses and remain governed by their individual provider access/terms. Public downloads of data and plotting code are hash-pinned separately.

PopGenLM code remains under the repository Apache-2.0 license. That license does not relicense third-party data or outputs. No credentials, full source matrices, raw Botanic score columns, raw AlphaGenome arrays, model representations, or the reserved 600-gene data are included.
